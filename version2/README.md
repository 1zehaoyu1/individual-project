# Version 2 — 故障检测优化 + Nucleo BSP

**完成时间**：2026-03-28

## 相比 Version 1 新增/改动

- 引入 STM32 Nucleo BSP（板级支持包），统一按钮和LED接口
- 重构故障检测逻辑：
  - 过流保护（>400mA 持续10秒）
  - 欠流保护（<6mA 持续10秒）
  - 温度超限（>60°C）触发 FAULT_WRONG_TEMP 状态
- MOSFET 热保护：温度 >30°C 自动断开负载（GPIO PB5）
- 代码结构优化，减少冗余逻辑
