# Version 3 — 库仑计数 SOC + 剩余时间估算

**完成时间**：2026-03-28

## 相比 Version 2 新增/改动

- **SOC 估算升级为库仑计数法**：
  - 开机用 OCV 查表初始化 SOC（11点查表，3S LiPo 9.0V–12.6V）
  - 运行中用 电流×时间 累积计算剩余电量
  - 小电流时（<50mA）进行轻度 OCV 校正，防止长期漂移
- **剩余时间（TTE）估算**：
  - 10秒滑动窗口平均功率
  - TTE = 剩余能量 / 平均功率
- **MOSFET 热保护完善**：NaN 温度读数时也触发断开
